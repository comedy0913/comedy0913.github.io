# comedy0913.github.io

Personal academic homepage of **Jiale Wang**, Ph.D. student at Xi'an Jiaotong University.

The site is built with [Jekyll](https://jekyllrb.com/) based on the [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template and hosted on GitHub Pages at <https://comedy0913.github.io>.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
